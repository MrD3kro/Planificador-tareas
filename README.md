# Clockydo
## Planificador de tareas: 
Este es un planificador de tareas diseñado para el día a día, tiene un temporizador que funciona para el momento, también, cuenta con un calendario que nos ayudaría a ver nuestra vista mensual de las tareas que tenemos.
